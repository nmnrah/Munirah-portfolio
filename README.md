# Munirah Asri — IT Portfolio

A responsive personal portfolio built with plain HTML, CSS, and JavaScript.

## Folder structure

- `index.html` — main portfolio page
- `style.css` — responsive styling and animations
- `script.js` — mobile menu, scroll effects, reveal animations, back-to-top button
- `images/` — add your project screenshots here
- `resume/` — add your PDF resume here

## Before publishing

1. Replace `your.email@example.com`.
2. Replace GitHub and LinkedIn links.
3. Add your real GitHub project URLs.
4. Put project screenshots in `images/`.
5. Add your resume as `resume/Munirah-Asri-Resume.pdf`.
6. Update dates/details if needed.
7. Test every button and link.

## Publish with GitHub Pages

Create a GitHub repository, upload these files, then enable GitHub Pages from the repository's Pages settings. Your `index.html` should be in the published root.
